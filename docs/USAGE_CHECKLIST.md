# 对照查看与研究记录使用核对

本清单描述操作及预期结果，不表示用户已完成人工验收。实际执行结果只记HANDOFF或受控研究记录；不要把患者身份信息写入反馈。程序原始影像只读，合成示例只验证工程流程。

## 一、准备可重复的合成练习

1. 完整解压发布ZIP，双击`CMVDBrowser/CMVDBrowser.exe`，保留旁边的`_internal`。首次应为空工作区。
2. 顶部“合成演示→MR首过灌注分析（完全合成）”，看到静息/负荷两条候选序列。
3. 选择静息序列。在“轮廓与曲线”分别选择心肌、血池，点击“居中参考轮廓”，再“计算原始曲线”。本步骤只供合成练习；真实数据需自行勾画并专业核对。
4. 转“灌注分析”，采集状态选静息，协议代码填`SYNTH-USE`；基线起帧1、基线帧数2、首过起帧3、末帧7。“计算当前MR平面”，再“保留MR结果至静息 / 负荷”。不要为了工程测试勾选未完成的审核项。
5. 选择负荷序列，重复两角色/曲线/分析操作，状态改负荷，使用同一合成协议和窗口，再保留。

预期：已保留两个MR状态，均保留合成/未审核标记。MPRI约2只是此合成样例的已知真值，不是患者结果或临床阈值。

## 二、静息／负荷对照

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 左侧“静息／负荷对照查看”。 | 同一病例内并排显示两侧；候选状态须人工核对，不从目录自动确诊。 |
| 2 | 确认联动默认关闭，只拖静息侧时间滑块。 | 负荷侧不跟随；主窗口选中序列、ROI和分析不改变。 |
| 3 | 开启相对时间联动，静息侧拖到第6帧。 | 此合成两侧都到第6帧/8秒；是最近真实采样，不是插值或生理同步。 |
| 4 | 若使用多层真实影像，独立选择两侧层面。 | 层面不自动联动；显示各自方向、LPS层面中心及单位，需专业确认同层。 |
| 5 | 关闭联动，改变一侧窗宽窗位。 | 另一侧显示窗不变；原始曲线和测量值不变。 |
| 6 | 检查两侧曲线及下方测量表。 | 只显示当前来源/层面/文档版本匹配的曲线与已保留MR；主要测量优先显示，其余可滚动查看。 |
| 7 | 在主窗口编辑一侧ROI或修改其分析窗口。 | 对应旧结果失效；不把旧曲线/测量继续当作当前有效结果，需要重算/保留。 |
| 8 | 快速拖动后松手；换序列或关闭对照窗口。 | 同网格等待保留旧图及其标签/ROI，最终到目标；换序列/出错清理旧图，关闭协作取消，不显示迟到结果。 |

时间轴、类型、单位不满足联动条件时，两侧继续独立显示。超出另一侧真实采样范围会提示并保留原位置，不补帧、不默认夹到末帧。cine/门控相位不按相对时间自动联动。仅索引对象在主窗口查看说明，不会强制进入对照解码。

## 三、导出、核对和继续工作

| 步骤 | 操作 | 预期结果 |
|---|---|---|
| 1 | 等两侧加载完成，取消未完成勾画，点“研究记录导出与核对”。 | 可导出；正在读取或勾画时不会保存错误位置。未选择对照也可导出主窗口工作。 |
| 2 | 点“导出当前病例研究记录”。 | 后台复核并保存至工作目录`outputs/research_records/<独立run>/`，旧记录不覆盖。 |
| 3 | 点“打开摘要”。 | 默认浏览器打开本机`summary.html`，可见范围、测量、分析窗口与复核状态，以及导出时的对照位置；不需要网络服务。 |
| 4 | 点“打开导出目录”，打开CSV。 | 有`measurements.csv`、`curves.csv`、`sequences.csv`、`issues.csv`。保留值/单位/真实时间，MR无帧长留空，缺项不补零；`synthetic_data`与临床验证标记明确。 |
| 5 | 核对帧号和单位。 | CSV帧/层面从0计，界面及摘要从1计；PET原始曲线BQML不称为MBF，MR半定量MPRI不称为绝对血流。 |
| 6 | 重新打开面板，选择“核对既有导出…”中的`research.json`或外层`bundle.json`。 | 文件哈希、固定文件集合及派生表/摘要一致性通过。此步骤不重读影像，也不是临床/解剖审核。 |
| 7 | 先保存未保存编辑，打开原病例或相同合成演示，点“从此记录恢复工作”。 | 原工作记录核对来源并复算后恢复ROI、曲线、分析与主窗口位置。对照快照/问题处置不自动恢复或升级审核。 |
| 8 | 在错误病例恢复，或仅复制一个JSON到其他目录再核对。 | 明确拒绝；原来的ROI/结果不被错误记录替换。 |
| 9 | 如需验证改写检测，将完整合成导出目录另复制到新的测试位置，只改副本某个CSV再核对。 | 拒绝改写副本；不要修改已完成原记录，更不要拿患者原件做此测试。 |
| 10 | 导出/核对任务可见期间点取消，或关闭任务窗口。 | 协作取消，不强杀线程；未完成目录无外层完成标记，不显示旧任务成功。若任务已完成，不把来不及取消记为取消失败。 |

导出目录的`work/`保存原格式工作记录，其内部完成标记可能先于外层完成；外层失败时不能把整份研究导出记为完成。请保留完整目录，完整性核对不等于像素匿名化、专业审核或临床验证。导出不包含影像；恢复仍需要原病例。

## 四、反馈建议

退出、打开另一病例/合成演示或恢复记录前若有未保存修改，会提示“保存工作／放弃修改／取消操作”。可在合成练习中先选取消确认ROI仍在，再选保存确认保存成功后才切换；保存失败/取消时应留在原工作。未完成勾画须先完成或取消。新目录不存在或索引失败/取消时，旧工作应保留。

研究导出、对照及序列问题窗口可按Esc或关闭按钮取消本窗口任务；任务已完成时关闭不会撤回已提交记录。小窗口/高缩放时可用窗口内滚动条访问完整控件。失败提示中的技术码与工作目录`outputs/runtime_logs/*-events.jsonl`可用于反馈，不需提供患者姓名或原始路径。

记录软件版本、显示缩放/分辨率、合成或真实受控模式、操作步骤、预期/实际行为与安全错误代码。截图默认使用合成演示。方向、解剖覆盖、运动、静息/负荷同层、协议及定量参考由专业人员分别复核；本清单的操作通过不自动勾选这些审核项。
