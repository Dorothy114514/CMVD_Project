# 心灌影像工作站

面向PET/MR心肌灌注研究的本机桌面应用，提供影像浏览、轮廓勾画、原始曲线、探索性灌注分析与研究队列管理。另有患者级融合基线训练框架；尚无真实诊断模型。真实清单、临床/诊断表和特征审核记录仍待补齐，阶段进度与验证范围见交接。

先阅读 [项目状态与交接](docs/HANDOFF.md)；AI协作规则见 [AGENTS.md](AGENTS.md)。

启动桌面浏览器（默认空工作区）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\desktop\start.ps1
```

可加`--synthetic`打开完全虚构的方向体模，或`--case-dir '单个已解压病例目录的绝对路径'`；也可在窗口点击“打开病例目录”，选择阳性/阴性目录下面的单个病例文件夹。原件只读，压缩包不会被打开，界面不显示姓名或原始UID。数据用途/静息/负荷均为候选，需人工核对。

主界面不放合成体模按钮；练习操作请从顶部“合成演示→影像浏览与轮廓练习（完全合成）”进入。看到圆环及白色方向标记即为成功，无需再选文件。它用来练习时间/层面滑块、逐帧播放、ROI放置/编辑/撤销、原始曲线和保存；不是把真实病例合成，也不提供诊断。试灌注计算请使用同菜单的“MR首过灌注分析（完全合成）”，其操作见下方D4说明。查看真实病例直接使用“打开病例目录”，无需先运行体模。

Windows发布版的使用方法：将`CMVDBrowser-Windows-x64-0.7.4.zip`完整解压，双击其中`CMVDBrowser/CMVDBrowser.exe`。exe旁的`_internal`文件夹必须保留；无需另装Python/Conda或打开网页。发布包只带程序、公开配置/空模板和运行库，病例与模型不打包；首次为空工作区。实际发布路径、验证结果和未覆盖范围见[交接日志](docs/HANDOFF.md)。

发布版默认把ROI/曲线/特征/队列与运行日志写入`%LOCALAPPDATA%\CMVDResearchBrowser\workspace-v1`，从“文件→打开工作目录”查看；也可用`CMVDBrowser.exe --workspace "E:\CMVD_Workspace"`明确指定。源码版默认仍保存到项目outputs/。已有工作目录的模板不会自动覆盖。分享程序只发送发布ZIP，研究结果和工作目录按受控资料单独管理。

静息／负荷对照与研究记录：

1. 打开病例，点击左侧“静息／负荷对照查看”。在同一病例内选择两侧序列；自动预选只使用采集状态候选，须人工确认静息/负荷、方向、解剖层面及协议。窗口只读，不修改主窗口的轮廓或分析。
2. 两侧时间、层面与窗宽窗位独立。可开启“联动相对时间”，按两侧各自起点后的真实时间选择最近采样，不插值；另一侧时间范围外保留原位置并提示。层面不联动；cine/门控等相位分支不启用时间联动，不作生理同步或配准。
3. 先在主窗口分别计算并保留静息/负荷MR结果或PET曲线，对照窗口即可显示来源和层面一致的曲线；测量表展示仍有效的保留MR结果。ROI/窗口修改会使对应旧曲线/分析失效，不会跨状态复制ROI。关闭对照窗口取消它的读取任务。
4. 点击“研究记录导出与核对→导出当前病例研究记录”。等待影像到达目标位置、完成或取消勾画后再导出。每次在`outputs/research_records/`新建独立目录，包含`summary.html`、`research.json`、测量/原始曲线/序列/问题CSV，以及`work/`下原格式的可恢复工作记录；不复制影像。HTML可本地打开，CSV为UTF-8 BOM。帧/层面在界面从1计、CSV从0计，保留真实时间/帧长与单位。
5. “核对既有导出…”选择`research.json`或外层`bundle.json`。检查完成标记、文件哈希和摘要/CSV一致性，不重读原影像或执行专业审核。要继续工作，先打开原病例，再点“从此记录恢复工作”；会按原规则核对来源并复算，替换当前未保存编辑，请先保存。对照位置与问题处置仅作导出快照，不自动恢复结论或升级审核。
6. 取消或关闭任务窗口会请求协作取消；中断输出保留且不当作完整记录。导出内容仍属受控研究资料。合成记录及CSV有明确标记；缺失测量不填零，临床验证、模型准入与诊断状态固定为未通过/不可用。

逐步操作及预期结果见[使用核对清单](docs/USAGE_CHECKLIST.md)，应用“帮助”菜单也提供简要步骤。设计与格式见[设计第22节](docs/DEMO_DESIGN.md#22-静息负荷对照与研究记录)。

序列状态与问题处理：

1. 打开病例后，左侧显示“未预览／读取中／已预览／读取失败／部分读取失败／已取消／仅索引”。可从上方筛选“有问题 / 提示”或“仅索引”。“已预览”只表示已加载部分帧、层面，不是全帧通过或专业审核。
2. 点击左侧“序列状态与问题清单”，查看问题阶段、中文原因、建议和来源。选择一行后点击“定位 / 重试序列”；有帧/层面记录时会定位原位置。头字段失败且无法确认所属序列的对象单独列出，不强行归属。
3. “仅索引”表示当前显示支持范围有限，可点击查看说明；不代表原件损坏。重复标识、缺帧或缩放异常等仍按严格读取规则处理，可记录“需医院核源/补导出”或“暂缓处理”，不能将处置记录当修复通过。
4. 点击“导出状态与问题”，在新的`outputs/sequence_reviews/`子目录保存`review.json`、`issues.csv`和完成标记，保留整个目录。它与影像“保存工作”分开；切换病例后会话记录清空，需先导出。失败和中断目录不作为完整记录。
5. “关联既有报告…”选择对应逐包检查JSON或以前导出的`review.json`，需同目录完成标记及文件哈希有效。总体汇总不可替代逐包报告；技术标识须匹配。导入仅增加历史提示，不恢复旧读取状态或处置结论，也不证明当前像素已通过、自动去重或放行训练。记录仍按受控研究资料保管。

保存结果并在下次继续工作：

1. 在“灌注分析”完成“计算当前MR平面”后，点击“保存当前MR分析”。仅有一个静息或负荷结果也能保存，包含对应轮廓、当前层曲线、计算参数和MR测量值。
2. 需要保留本病例的整体进度时，点击顶部“保存工作”。记录当前病例各已标注序列的ROI、当前及已保留结果所用的曲线、静息/负荷保留结果、已导入的PET工作站结果与MR参考，以及分析参数、当前序列/帧/层面、窗宽窗位、缩放与页签。尚未计算曲线也可保存已完成的轮廓。保存不会覆盖旧记录。
3. 从“文件→打开最近工作记录目录”找到本次结果；完整目录保存在工作目录的`outputs/work_records/<独立run>/`，其中`work.json`用于恢复，`roi.json`、可选`curves.json`及MR测量表`measurements.csv`用于查看/导出，`bundle.json`是最后写入的完成标记。请保留整个目录。
4. 重启后先打开**原病例目录**，再点顶部“恢复工作…”，选择所保存目录内的`work.json`。合成记录需先打开对应合成演示。程序核对来源、几何、时间、单位和文件哈希，并从原图重新计算曲线/分析；全部通过后才恢复界面。来源缺失、错配、文件变化或复算不一致会拒绝恢复。

退出、换病例、切换合成演示或恢复替换前，若有未保存轮廓/分析，程序提供“保存／放弃／取消”。选择保存会等待完整病例工作保存成功再继续；失败或取消保存会留在当前工作。未完成勾画须先完成或取消，单项MR保存不代表整个病例均已保存。新病例目录不存在、索引失败/取消或没有可索引序列时保留旧工作；读取期间暂不显示旧病例图像，通过“读取病例”窗口可取消。

保存/恢复在后台进行，期间可从“文件→取消保存或恢复”取消。工作记录不复制影像、不保存患者源路径；原影像必须另行保留。它是手动保存点，不提供崩溃后的自动保存恢复或跨电脑迁移保证；撤销历史从恢复后重新开始。复核状态按记录保留，未审核结果不会升级为已审核；工作记录也不替代研究队列所需的完整双灌注特征包。存储与恢复约定见[设计第20节](docs/DEMO_DESIGN.md#20-结果保存与工作恢复)。

研究导出、对照和序列问题窗口的Esc与关闭按钮均请求协作取消，迟到结果不会发布；再次操作可重新打开窗口。小窗口或高缩放下可使用窗口内滚动条访问完整内容。后台失败显示安全错误码提示，并写入工作目录`outputs/runtime_logs/*-events.jsonl`，不记录患者姓名、原始UID、患者日期、源路径或任意异常文本。

重建发布包使用已准备好的项目外PyInstaller工具和独立构建依赖锁，不能把项目目录整体压缩作发布包：


左侧选择PET、MR逐平面灌注或cine；下方滑块控制时间/层面，窗宽/窗位只改变显示。浏览帧率可设1–30 fps（默认15），播放等待当前帧完成Qt绘制后推进，慢读取时实际速度会降低；这不是实际采集速度。快拖时保留上一帧及其时间/层面标签，状态栏显示目标，松手立即请求最终位置；拖动会暂停播放。双击序列或按回车可重试，支持后台加载与取消。鼠标滚轮缩放、中键平移；左键行为由图像上方“鼠标工具”选择。方向为原始采集平面，非强制标准轴位。当前明确显示“模型未配置”，没有真实诊断。浏览约定见[设计稿第12节](docs/DEMO_DESIGN.md#12-d2桌面浏览)。

左侧有些对象只能索引、暂不支持显示，例如截图、多帧或其他未支持分支；支持分支也可能因重复SOP、缺帧、缩放或几何问题被拒绝。两者需区分，不能把“无法显示”一律理解为影像损坏。遇到问题先保留错误提示和序列定位，通过问题清单定位/记录或导出研究记录，不删除、改头字段或强行拼接。

D3使用右侧“轮廓与曲线”面板；关闭面板后可从“视图”菜单恢复。已有旧窗口需关闭后重启：

1. 选择序列、层面和参考帧，在“轮廓与曲线”选“心肌”或“血池”，选择“拖出椭圆”或“逐点勾画”，点“在图上勾画”。椭圆在目标位置按住左键拖出范围，松开完成；逐点沿边界左键选点，按Enter、双击最后一点或点回起点闭合。Backspace或Ctrl+Z撤回一个草稿点，Esc或右键取消整次草稿；有效完成才修改原轮廓。原有居中几何起点保留为“居中参考轮廓”。
2. 完成后自动进入“编辑轮廓点”，可拖控制点细调，点偏到背景不会拖图或拖动整个ROI。心肌可选择“只编辑心外膜”或“只编辑心内膜”，另一条边界锁定；也可用“在图上勾画”重画所选边界。一起新建时，内膜按外膜缩小为手工起点，必须另行核对，不能当作自动分割；单独重画一条边界会保留另一条，交叉/越界则拒绝提交。点击线段加点，右键控制点删点（至少3点）。
3. 切换时间帧逐帧检查，必要时选择“仅修正当前帧”修改或重画轮廓；可用“取消本帧修正”恢复参考。参考轮廓用于所有未单独修正帧，修正之间不插值；已有独立轮廓的帧应在当前帧模式编辑。切帧、切序列/病例、角色、编辑范围、工具或离开轮廓页会取消未完成草稿。
4. 点击“计算原始曲线”，读取当前层的完整时间序列，显示心肌/血池均值和当前帧像素数、面积。PET保留BQML及帧长，MR保留原始信号与非等间隔时间，cine保留当前层实际触发时间。静态图像可以保存ROI，不能凭空生成时间曲线。
5. 点击“保存ROI / 曲线”，在`outputs/roi/<时间戳-随机ID>/`新建快照；“载入已存轮廓”选择其中的`roi.json`。ROI覆盖该序列所有已标注层，`curves.json`/`curves.csv`仅包含当前计算层；来源、几何或时间不匹配会拒绝加载。换病例前请保存，跨病例不保留未保存标注；整体工作保存/恢复见上方步骤，未完成草稿不入保存点。

需要整体平移某个轮廓时，上方鼠标工具选“移动整个轮廓”，左键拖动当前所选心肌/血池的轮廓内部或边线，心肌内外膜一起平移；要左键拖图则选“平移影像”，此时ROI锁定。任何工具下均可中键平移、滚轮缩放，误移视图可点“适应视图”。

图像上方和ROI页均有“撤销/重做”：`Ctrl+Z`撤销，`Ctrl+Y`或`Ctrl+Shift+Z`重做，支持拖点/整体移动、增删顶点、放置/删除ROI、内膜开关、本帧覆盖/恢复及ROI重载。一次拖动只计一步；无效编辑可撤销回上次有效轮廓。历史按序列隔离，当前病例合计最多50步/16 MiB，切回同序列可继续使用，换病例或退出清空；输入框仍使用自身的文本撤销。撤销后只恢复轮廓和编辑帧，不恢复复核勾选、曲线或保留特征，需重新复核/计算；历史不能代替保存快照。

ROI越界、自交、空区域或心肌/血池重叠会阻断相应计算。轮廓修改会使旧曲线与人工复核状态失效。仅在实际核对后勾选方向/覆盖和轮廓/运动复核；它们是本地人工确认，不是临床定量验证。当前运动处理是**逐帧手工修正ROI**，不做自动配准、图像重采样或MBF/MFR计算；真实测量与独立查看器人工核对仍待完成。数值和存储约定见[设计稿第13节](docs/DEMO_DESIGN.md#13-d3人工roi与原始曲线)。

   曲线联动：计算原始曲线后，“轮廓与曲线”和“灌注分析”两页都可查看同一层曲线。曲线上方选“定位影像帧”，左键点击即可跳到最近的实际采样帧；滑块/播放也同步游标。等待影像时，实线表示已显示帧，虚线表示正在加载的目标，不提前把旧图标成新帧。

   窗口修改后，原候选结果、当前来源/层面的保留MR及相关参考/配对确认失效，窗口复核取消勾选；重新核对后点击“计算当前MR平面”，需要时再保留静息/负荷结果。其他已保留状态不会仅因换序列被删除。PET/cine等曲线只提供定位，不显示MR窗口，也不会转称MBF/MFR。工作保存保留实际帧号参数，恢复后重建两页色带；未完成的两次点选不保存。

2. 分别“保留”静息和负荷MR结果，再核对同一解剖平面和剂量/序列/协议可比较性。当前一次仅配对一个平面，MPRI为两状态归一化斜率之比；不自动把长轴/短轴或不同层面平均，也不是绝对MBF。归一化斜率采用心肌/血池斜率比，单位为`1`，与旧合成输入中`s^-1`示例字段不自动互换。
3. PET：在ROI页分别计算两状态动态PET双ROI曲线，D4页手动选择状态并保留。导出PET填写模板后，将已审核工作站的全左室MBF、单位、方法/软件版本、协议/示踪剂、参考和审核者代码填入JSON，再导入。模板MBF默认空，不得为真实病例填演示数字；当前仅支持`mL/min/g`，不是从BQML或TAC自行算MBF。导入核对本地来源、ROI及曲线签名；这不等于独立验证工作站MBF数值。
4. 可导出MR参考模板，填写独立参考值及事先约定的工程容差后核对；模板不预填参考值或容差。保存特征/QC快照至`outputs/features/<新目录>/`，包含JSON/CSV、原始输入/方法/单位/来源和完成标记；无PET或MR参考时可保存已配对MR预览，缺项明确标记。ROI修改会使相关保留结果失效；来源文件变化会拒绝导入/导出。当前不会向合成模型传入这些结果，也不生成诊断。
